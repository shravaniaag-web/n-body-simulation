# N-Body Simulation (Particle Falling into Sun)

This project simulates the motion of a particle under the gravitational influence of the Sun.

## Features
- Uses Newton’s law of gravitation
- Numerical integration (Euler method)
- Visualized using Matplotlib

## Tools Used
- Python
- NumPy
- Matplotlib

## Output
Shows trajectory of particle orbiting/falling into the Sun.
